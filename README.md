# ABTalks Redesign

A modern mobile-first redesign of the ABTalks 60-Day Coding Challenge platform built for ViCodathon 2026.

## Features

- Responsive Landing Page
- Student Dashboard
- Challenge Day Page
- Modern Card UI
- Mobile First Design
- Clean Dashboard
- Progress Tracking
- Responsive Layout
